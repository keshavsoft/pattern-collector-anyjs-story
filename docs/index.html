Pattern Collector Line Extractor

A modular ES module to scan file contents and pull structured line details with capture variables using regular expressions.

Line Tracking Configurable Regex 3 Sub-Modules

Installation

Add the pattern collector to your Node.js project using npm or yarn:

npm install pattern-collector-anyjs-story

Or using yarn:

yarn add pattern-collector-anyjs-story

Quick Start

Import the default function and pass your code text along with your configuration template name:

import collectPatternStory from 'pattern-collector-anyjs-story';

const results = collectPatternStory({
  fileContent: sourceCode,
  fileType: 'fromEndPointsJs'
});

🎯 Why this Repository?

Developing Express.js applications usually requires editing routing files manually whenever a new API, table, or version is added.

Every time a new endpoint is created, developers must locate the correct import, router.use(), router.get(), router.post() position and insert new code without breaking existing formatting.

pattern-collector-anyjs-story solves this problem by reading existing JavaScript files, identifying routing patterns, calculating insertion positions, and returning structured information that other generators use to update files automatically.

📌 Example 1 — Endpoint Generator

Run 

node ./test/v15/forEndPoints.js

This script scans the existing end-points.js file.

It detects

  • Existing import statements
  • Existing router.get()
  • Existing router.post()
  • Existing router.put()
  • Existing router.delete()
  • First matching line
  • Last matching line

After calculating insertion positions it automatically creates the missing code.

Before



import funcFromfind from "./find/controller.js";

router.get("/find/:ledgerName", ...);

After



import funcFromfind from "./find/controller.js";
import funcFromshowAll from "./showAll/controller.js";

router.get("/find/:ledgerName", ...);
router.get("/funcFromshowAll", ...);
💡 Only the required lines are inserted. Nothing else in the file is modified.

📌 Example 2 — Routes Generator

Run 

node ./test/v15/forRoutesEnd.js

The script reads routes.js and identifies

  • router imports
  • router.use()
  • first matching line
  • last matching line
  • available insertion position

Before



import { router as routerFromFold1 }
from "./Fold1/end-points.js";

router.use("/table1", routerFromFold1);

After



import { router as routerFromFold1 }
from "./Fold1/end-points.js";

import { router as routerFromFold2 }
from "./Fold2/end-points.js";

router.use("/table1", routerFromFold1);

router.use("/routerFromFold2", Fold2);
The package automatically calculates the correct insertion location instead of appending code randomly.
